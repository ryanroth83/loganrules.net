Clone Hero Setup

Welcome to the Clone Hero section where I go over how to use it with a Wiitar! You can use it to play guitar hero-style games with a real guitar controller. The only hardware you'll need is a Wiitar controller with a wiimote and a computer with the necessary software installed.

Software Needed

To use Clone Hero with a Wiitar, you'll need the following software:

  • Clone Hero
  • Wiitar Thing
  • ViGEmBus
  • Highly Recommended: Dolphin

Setup Instructions

Here are the steps to set up Clone Hero with a Wiitar:

  1. Go throught the install process for ViGEmBus. It will warn you about Windows protection features but click "More info" and then "Run anyway".
  2. Next, extract Wiitar Thing into any folder on your computer. I use my Documents folder. You only need to extract the "Wiitar Thing" part, not the "Wiitar Thing - SCP Driver" is not needed.
  3. After that, install Dolphin (highly recommended). There is another method with using Control Panel but it is more complex and not recommended for beginners.
  4. Finally you can install Clone Hero Launcher, then install the latest version of Clone Hero.

How to setup controller

Here are the steps to set up your Wiitar controller:

  1. Open Dolphin and on the top row there is a button that is labeled "Controllers". Click on it.
  2. Make sure Emulate the Wii's Bluetooth Adapter is selected. DO NOT USE PASSTHROUGH.
  3. Press 1 + 2 on your wiimote to put it into pairing mode.
  4. Press "Continuous Scanning" every 5 seconds in the Dolphin interface until your controller vibrates and is detected.
  5. Once your controller is detected, you have successfully set it up. You can now close dolphin.

How to setup Wiitar Thing

This section will guide you through the process of setting up Wiitar Thing:

  • Run the Wiitar Thing executable.
  • Because we have the wiimote paired to our computer, Wiitar Thing will automatically detect it and it will show up on the left side of the interface.
  • Click on the button in the box that says connect.
  • In the list select "Player 1" or the appropriate player number.
  • Once you have selected the player, hold down 1 + 2 on your wiimote. Then click "ok" to confirm. You should see the Wiimote has changed to a guitar.
  • Click the button that says, "Click here to open controller test menu".
  • If you see something that says XBOX 360 Controller, then your Wiitar Thing is working correctly. If not click disconnect next to your wiimote and repeat steps 3 - 6 until it shows.

Using it with Clone Hero

Once you have set up your Wiitar controller and Wiitar Thing, you can now use it with Clone Hero. Simply launch Clone Hero and configure inputs by pressing spacebar.

If you encounter any issues, make sure all the software is up to date and that your Wiitar controller is properly paired with your computer.

If you still have issues, check the Clone Hero forums or the Wiitar Thing GitHub page for troubleshooting tips and support. Or use my contact information to get in touch.
